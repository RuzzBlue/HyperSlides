Install

Navigate to the wallet publisher’s official website or its verified app-store listing. Install and open the application. Avoid ads, DMs, and search-result lookalikes.

Safe install path

  1. Open your bookmarked official site (not a sponsored result)
    • Check the domain spelling carefully
    • Prefer HTTPS lock + expected publisher name
  2. Download or open the store listing from that page only
  3. Install, then launch the app once
  4. Skip any “support chat” offers that appear during first run

Red flags

  • URLs that add extra words like secure- or -wallet-login
  • Installers sent as email attachments
  • QR codes from strangers claiming to speed up setup

When the app opens cleanly and asks you to create or import a wallet, move on to Create & backup.
