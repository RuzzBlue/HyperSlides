Overview

Create a learning wallet using only an official wallet source and a quiet, private setup location. This section is demo-expanded so you can scroll through richer lab content.

Never submit a seed phrase, private key, or unredacted backup as evidence.

What you will practice

  • Finding a verified download path (website or app store)
  • Creating a wallet without photographing the recovery phrase
  • Confirming a receive address before sharing it

Setup checklist

  1. Prepare the space
    • Quiet room, no cameras pointed at the screen
    • Paper + pen ready for an offline backup
  2. Decide the wallet brand you will use for learning
    • Prefer one you already researched in the lessons
    • Bookmark the official URL before installing
  3. Plan how you will store the paper backup afterward

Tip: keep the Lab brief tab open nearby for links and downloads while you work.
