Review & send

Review recipient, asset, network, amount, and fee one final time. Send only the test amount. Never approve an unfamiliar transaction or signature request.

Final review order

  1. Read the summary screen top to bottom
    • Recipient
    • Asset / network
    • Amount
    • Fee
  2. Reject any unexpected permission prompts
  3. Confirm send only after the four checks above

If something feels off

  • Cancel and restart from the prepare section
  • Do not “just try again” with a larger amount
  • Capture a redacted note of what looked wrong
