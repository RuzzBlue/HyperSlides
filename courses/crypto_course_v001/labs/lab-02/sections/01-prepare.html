Prepare the transfer

Choose a small test amount. Copy a destination you control, then compare the beginning and end of the pasted address. Confirm that both wallets use the same network.

Pre-flight checks

  1. Pick the destination
    • Prefer an address you already verified in a prior lab
    • Avoid pasting from chat apps when possible
  2. Confirm network + asset
    • Same chain on both wallets
    • Correct token symbol (not a lookalike)
  3. Set a tiny test amount and note the estimated fee
  • Recipient start/end match what you intended
  • Amount is intentionally small
  • Fee fits your learning budget
