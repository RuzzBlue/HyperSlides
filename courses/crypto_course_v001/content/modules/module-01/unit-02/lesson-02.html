Transactions, Blocks & Confirmation

A transaction proposes a state change: move assets from one address to another. Confirmation means the network included it in history — more confirmations generally make reversal harder.

Step 1

Check the network

Address formats and fees differ. A correct address on the wrong network can still lose funds.

Step 2

Review the intent

Verify recipient, asset, amount, network, and fee before you approve.

Step 3

Wait for status

Use a reputable explorer or wallet status to watch pending → confirmed.
