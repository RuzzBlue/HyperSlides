Create & backup

Create a new wallet. Write the recovery phrase on paper. Confirm the app’s verification prompts. Do not store the phrase in email, screenshots, or cloud notes for this exercise.

Backup sequence

  1. Choose Create new wallet
    • Set a device unlock / app PIN if offered
    • Decline cloud backup features for this learning lab
  2. Reveal the recovery phrase once
    • Write it carefully on paper
    • Double-check word order before continuing
  3. Complete the in-app confirmation of a few words
  4. Store the paper in a private place before leaving the desk

What “good” looks like

  • Phrase never left visible on a second monitor
  • No photos of the phrase
  • You can still unlock the wallet with your device PIN afterward
